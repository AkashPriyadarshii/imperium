Engineering Pillars

Built on Discipline & Local Math

01 // DB

Drift SQLite Background Isolate

Queries and aggregates execute in a separate Dart isolate running over native `sqlite3`. The main UI thread never stutters, maintaining 120Hz frame rates regardless of log volume.

02 // BIO

Hardware Biometric Authentication

Integrated via Android BiometricPrompt (`local_auth` 3.0.2). Fingerprint and face unlock protect your ledger locally with automatic fallback on unequipped devices.

03 // MATH

Pearson Correlation Engine

Zero LLM hallucinations. Computes true statistical indicators on CPU, discovering mathematical correlations between paired time-series (e.g. study hours vs. sleep duration, $N \ge 5$).

04 // PRIVACY

Zero Network Permissions

`android.permission.INTERNET` is completely absent from the manifest. Data never leaves your device's private sandbox.

05 // SAF

Storage Access Framework & Armored Reset

Full JSON data portability. Export backups to any user-designated storage provider. The armored reset protocol mandates a verified backup before wiping data.

06 // TIME

Asymmetric 4 AM Rollover

Day logs roll over at midnight, but late-night entries (e.g. 02:00 AM sleep or study sessions) logically bind to the preceding calendar day via a 4-hour offset algorithm.
